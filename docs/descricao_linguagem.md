# Linguagem Xuxu

> **A linguagem Xuxu** ela vai ser uma linguagem tão fácil que fica sem graça igual o chuchu. Simples, direta, sem enfeite.

Ela possui **condições, loops, estruturas de dados, tratamento de erros, módulos** e um diferencial: **scheduling nativo** pra emitir alertas e chamar funções específicas em horários ou intervalos determinados.

# Scheduling Nativo

O grande diferencial da linguagem Xuxu é possuir **scheduling nativo**, permitindo emitir alertas e chamar funções específicas em horários ou intervalos determinados.

| Conceito  | Xuxu                                 |
| --------- | ------------------------------------ |
| `agenda`  | bloco de scheduling                  |
| `alarme`  | dispara em horário fixo              |
| `dacerta` | execução recorrente                  |
| `avisa`   | emite notificação                    |
| `cutuca`  | chama função específica em um evento |
